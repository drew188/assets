# assets

Static image host for Pointer Property, serving logos and graphics used in Cloudbeds Guest Experience (Whistle) email templates.

Live at `https://assets.pointerproperty.com.au` via GitHub Pages.

## Important: URLs here are permanent

Once an image URL is used in a sent guest email, it can never be renamed, moved, or deleted. Cloudbeds email templates reference these URLs directly and there is no way to update a message that has already been sent. Add new files instead of changing existing ones.

## Structure

- `riverhouse/` - The River House Bali
- `oceanfarm/` - Ocean Farm
- `brayhouse/` - Bray House Teton Village
- `shared/` - Pointer Property group assets

## Guidelines

- Lowercase, hyphenated filenames, no spaces. Include dimensions where helpful, e.g. `logo-600.png`.
- Max width 600px for email use. PNG for logos (transparency), JPG for photography.
- Keep individual files under ~100KB.
- This repo is public. Logos and decorative graphics only - nothing private or sensitive.
